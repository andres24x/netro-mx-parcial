# NETRO MX — Portafolio del Parcial · Equipo 8

Sitio web que integra todas las actividades trabajadas durante el parcial de
**Negocios Digitales en la Industria del Entretenimiento** (Lic. Comercio Electrónico),
sobre el subsector asignado: **Prensa y Noticias**.

Cada actividad está explicada y disponible para descarga en su formato original.

## Contenido

| # | Actividad | Formato |
|---|-----------|---------|
| 01 | Lienzo de Disrupción Digital y Modelos de Ingresos | XLSX |
| 02 | Bases del proyecto y propuesta de modelo de negocio (NETRO MX) | PDF |
| 03 | Informe de Tendencias de Marca (Google Trends) | HTML |
| 04 | Cuadro de Resultados de la Investigación | DOCX |
| 05 | Informe de investigación: creación con perspectiva humanista | PDF |
| 06 | Prototipo web de NETRO MX | HTML |

## Stack

Sitio estático: HTML + CSS + JavaScript sin dependencias.
Estética *liquid glass morphism* sobre fondo animado (canvas + video), tipografías
Poppins, Source Serif 4 y JetBrains Mono.
